# IT Support Incident Ticket Template

**Purpose:** Standard template for documenting, escalating, and closing technical support requests.

---

```text
================================================================================
INCIDENT TICKET RECORD
================================================================================
Ticket ID:        INC-[YYYYMMDD]-[####]
Date Opened:      YYYY-MM-DD HH:MM
Reported By:      [User Name / Email]
Department:       [Administration / Finance / IT / Operations]
Location:         [Office / Room / Desk]
Severity:         [Low / Medium / High / Critical]
Affected Asset:   [Asset Tag / Computer Name / Serial Number]
Category:         [Hardware / Network / Operating System / Email / Software]

--------------------------------------------------------------------------------
1. SYMPTOM DESCRIPTION
--------------------------------------------------------------------------------
User Description:
[Exact problem statement reported by user]

Observed Behavior:
[Technical description of failure observed by IT technician]

Error Messages / Error Codes:
[Exact text or screenshot references]

--------------------------------------------------------------------------------
2. INITIAL TRIAGE & SCOPE ASSESSMENT
--------------------------------------------------------------------------------
Scope:            [Single User / Multi-User / Subnet-Wide / Facility]
Physical Check:   [Link Lights / Cable State / Power Indicator]
Network Check:    [IP Assigned / Gateway Ping / DNS Resolution]

--------------------------------------------------------------------------------
3. INVESTIGATION & ACTIONS PERFORMED
--------------------------------------------------------------------------------
Step 1: [Action taken] -> Result: [Observed outcome]
Step 2: [Action taken] -> Result: [Observed outcome]
Step 3: [Action taken] -> Result: [Observed outcome]

--------------------------------------------------------------------------------
4. ROOT CAUSE ANALYSIS
--------------------------------------------------------------------------------
Root Cause:
[Technical explanation of why the failure occurred]

--------------------------------------------------------------------------------
5. RESOLUTION & PREVENTATIVE ACTION
--------------------------------------------------------------------------------
Corrective Action Applied:
[Specific configuration change, hardware replacement, or command executed]

Verification Steps:
[Tests performed to verify service restoration]

Preventative Measure:
[Actions taken to prevent recurrence or update to standard SOP]

--------------------------------------------------------------------------------
6. TICKET CLOSURE
--------------------------------------------------------------------------------
Resolution Status: [Resolved / Transferred / Escalated]
Closed By:        [Technician Name]
Date Closed:      YYYY-MM-DD HH:MM
User Confirmed:   [Yes / No]
================================================================================
```
